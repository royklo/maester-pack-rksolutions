The primary user of a device is the person it belongs to. When that account is disabled, the person has usually
left, and the device should be collected, wiped or given to someone else. The test lists Windows devices whose
primary user is disabled in Microsoft Entra ID.

#### Remediation action

1. For each device below, collect it, then wipe or retire it in the [Microsoft Intune admin center](https://intune.microsoft.com)
   under **Devices** > **Windows**.
2. Or change its primary user to the person who uses it now (**Properties** > **Primary user**).
