A noncompliant device fails one or more rules of its compliance policies, and Conditional Access can block it from
company data. The test lists every noncompliant Windows device with each rule it fails, as Intune reports it.

#### Remediation action

1. In the [Microsoft Intune admin center](https://intune.microsoft.com), go to **Devices** > **Compliance**.
2. Open each device listed below and fix the failing setting, or sync the device if it was fixed already.
